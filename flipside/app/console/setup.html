setting up console.

About ten minutes, once. iPhone menus move around between iOS versions, so the paths below are close, not exact.

1. put it on the home screen

  1. In Safari, open flipside.ownyourmedia.club/flipside/app/console/
  2. Share › Add to Home Screen. Keep the name Console.
  3. From now on, open it from that icon. That's what makes it full screen, with no Safari bars.

2. bring your tapes in

  1. Tap the tape strip. Flipside opens on the deck.
  2. Sign in to Plex there, once. Console keeps its own copy of Flipside (an iPhone keeps each Home Screen app separate), so this is a fresh sign-in.
  3. Tapes kept on Plex come down. Anything missing: Paste a Tape Link, or send it to yourself.
  4. ‹ console. at the top takes you home. The tape keeps playing.

3. make two shortcuts

Phone and Finch don't have a link an app can open, so Console asks Shortcuts to do it.

  1. Shortcuts › + › Add Action › Open App › Phone. Name it exactly Console Phone.
  2. Same again with Finch, named Console Finch.
  3. Shortcuts flashes on screen for a moment before the app opens. That's normal.

If any other button doesn't open its app, make a shortcut for it the same way, then in Console tap set and change that button to shortcuts://run-shortcut?name= plus the shortcut's name (a space is %20).

4. a focus with one icon

  1. Settings › Focus › + › Custom. Call it Console.
  2. People: let your favorites through. Apps: Phone, Messages, Signal.
  3. Customize Screens › Home Screen: make a page with only the Console icon on it and pick just that page.
  4. Turn the Focus on. Swiping up lands on that one page, one tap from Console.

5. take the color out (optional)

  1. Settings › Accessibility › Display & Text Size › Color Filters › Grayscale.
  2. Settings › Accessibility › Accessibility Shortcut › Color Filters, so a triple-click of the side button turns it on and off.

6. last bits

  1. In Console, tap set and find your town for the weather.
  2. Pick light or dark with the button up top. It stays where you left it.
  3. Tap the line at the bottom to write yourself a note.

Guided Access (Settings › Accessibility) can lock the phone into Console if you want to go all the way.
